A masthead in three type colors sits over a navy tab strip, then a gold search band with an input, a button and a language select. Below that the page is a four-column table directory, each cell fenced by a one-pixel rule and headed by a colored bar, with a tool rail at the right. The footer is one dense row of links over a copyright line.

[META]
The portal as a directory. Every region is a table cell and every cell is fenced, so the page reads as a grid of equal claims rather than as a hierarchy. The gold band is the only high-energy element, and it is spent on the search box, which is the whole point of the page.

[RELEVANCE]
The fenced-column directory is a strong period reference, but this template is a document, not a portal, so it has no use for four competing columns. The gold-band emphasis trick is worth remembering for a single call to action.
